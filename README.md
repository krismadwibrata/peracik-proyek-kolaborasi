# Peracik Proyek Kolaborasi Antar Mapel

Aplikasi satu berkas (HTML) untuk membantu guru SD, SMP, dan SMK menyusun proyek kolaborasi antar mata pelajaran dengan bantuan AI: Ide proyek, Peta keterkaitan, dan Perintah job sheet.

Dibuat untuk SMK Telkom Purwokerto.

## Cara memakai
Buka tautan GitHub Pages repositori ini, atau unduh `index.html` lalu buka di peramban. Tidak perlu instalasi, tidak ada server, dan data tersimpan di peramban Anda sendiri.
